# Kickstarter 上线前配置评分 — 结果摘要（v2：USD-only 口径）

生成方式：`python ks_v2/run_all.py --stage all`（单命令可复现；随机种子固定 42）。
所有指标均为**时间外推**口径：训练 ≤2022 年，测试 ≥2023 年，测试集从未参与拟合、调参或校准。

---

## 0. 一句话结论

在 40.8 万个 USD 结算项目中，"品类 + 目标金额 + 时长 + 发起人历史（含既往成功率）+ 标题/简介文本"可以把
**上线前是否能达标**的排序做到 **AUC 0.885（95% CI 0.882–0.888）**，且概率已经足够准（ECE 0.003），
头部十分位的实际达标率 **99.5%**（是基准的 1.55 倍）。模型同时给出"成功率 vs 成功时募资额"的权衡曲线，
以及一张 204 格的**配置达标率评分表**和分品类**文案关键词面板**——三件东西都直接对应选题说明里的三条输出。

---

## 1. 数据与口径

| 项目 | 数值 |
|---|---|
| 原始清洗样本 | 673,839 行 × 81 列 |
| 保留 `currency == USD` 且 `usd_type` 非空 | **408,347 行**（达标率 0.4950）|
| 剔除 | 非 USD 币种 213,243；无二值结果（canceled）44,977；`usd_type` 缺失群 7,272 |
| 训练窗口 ≤2022 | 353,913 行，正类率 **0.4724** |
| 测试窗口 ≥2023 | 54,434 行，正类率 **0.6425** |
| 特征 | 4 个类别特征（品类/子品类/地点类型/州，州取 top-20）+ 14 个数值特征；文本另走 TF-IDF(15k, 1–2gram) 通道 |
| 排除 | 10 个结果期泄漏列（pledged、backers_count、staff_pick 等）全程不进入特征：`features.check_no_leakage` 断言 |

> 为什么砍成 USD-only：币种混杂时 `log_goal` 跨币种不可比，且 13 个汇率修订列口径不稳。代价是丢掉 31% 样本
> （含港/日等高成功率市场），这一点在报告里必须主动交代，不能当"全量结论"卖。

## 2. 验证设计（结论可信的前提）

1. **不做随机切分**：达标率从 2015 年 0.336 一路爬到 2024 年 0.645，随机切分会让"未来信息"漏进训练。
2. **六折滚动起点验证**：验证年 2017…2022，每折只用该年之前的数据拟合（含词表、缺失插补、标准化、格子率）。
3. **一次外推测试**：2017–2022 上选型、2023 起只看一次。
4. **概率校准只用折外预测**：isotonic 在折外预测上拟合，再用于测试。
5. **重复抽样置信区间**：配对 bootstrap 2,000 次给 ΔAUC 区间，避免"小数点后第三位也算赢"。

## 3. 主结果一：模型比较

滚动验证（2017–2022 六折，均值 ± 标准差）与一次性外推（2023+，n=54,434）：

| 模型 | 滚动均值 AUC | 滚动 sd | test AUC | test PR-AUC | test Brier | test 准确率 |
|---|---|---|---|---|---|---|
| B0 多数类 | 0.5000 | 0 | 0.5000 | 0.6425 | 0.2586 | 0.3575 |
| B1 仅 log_goal | 0.6500 | .034 | 0.7068 | 0.7993 | 0.2234 | 0.6272 |
| B2 历史格子率（品类×金额×时长）| 0.7124 | .031 | 0.7597 | 0.8363 | 0.1995 | 0.6888 |
| LR（可解释基线）| 0.8193 | .020 | 0.8571 | 0.9148 | 0.1485 | 0.7760 |
| 浅树 depth=5 | 0.7694 | .029 | 0.8277 | 0.8894 | 0.1622 | 0.7425 |
| RF 300 棵 | 0.8298 | .022 | 0.8706 | 0.9240 | 0.1420 | 0.7903 |
| HistGB（结构化）| 0.8422 | .019 | 0.8791 | 0.9291 | 0.1347 | 0.8034 |
| **HistGB + 文本分（选定）** | **0.8559** | **.013** | **0.8848** | **0.9318** | **0.1306** | **0.8093** |
| 0.5·结构化 + 0.5·文本 平均 | 0.8538 | .015 | 0.8847 | 0.9319 | 0.1309 | 0.8098 |

选定模型：**HistGB（原生类别编码）+ 文本分**。理由：滚动均值最高、跨折波动最小（sd 0.013，说明不是某一年运气好），
且比第二名（简单平均融合）差异只有 0.002——**说明增益来自"有文本"，而不来自"融合技巧"**，这点对答辩很重要。

配对 bootstrap（test）：HGB_text − HGB **+0.0057 [0.0046, 0.0067]**；− RF +0.0141；− LR +0.0277；
− B2 +0.1251；− B1 +0.1780。全部区间不含 0。

## 4. 主结果二：排序质量与稳定性

- **分年 AUC 单调走强**：折外 2017 0.845 → 2022 0.876；外推 2023 0.881、2024 0.883、2025 0.890、2026 0.890。
  → 没有随时间衰减，排除了"模型只拟合早期模式"的怀疑。
- **十分位 lift**：D1 实际达标率 **0.9947（lift 1.548）**，占全部成功项目的 15.5%；D10 仅 0.0693（lift 0.108），
  单调性完整。业务读法：模型说"很稳"的项目，几乎必成；说"很悬"的项目，十有八九失败。
- **分组 AUC**：technology 0.934、games 0.909、comics 0.882，最低的 theater 0.780、food 0.785、film&video 0.795；
  金额档 100–500k 0.938；时长 1–7 天 0.957。→ 弱在"低基础率 + 少样本"的格子，报告里按格子标注 n 即可。
- **头条 CI**：AUC 0.8848，95% CI [0.8819, 0.8876]。

## 5. 概率校准与先验漂移

- 原始概率 **Brier 0.1306 / ECE 0.0032**——已经非常准，**不需要再校准**。
- isotonic 反而更差（Brier 0.1319 / ECE 0.0284）：折外样本上拟合的单调映射把细分区域压平了。**结论：不采纳**（如实写进报告，比"上了校准就一定更好"诚实）。
- 训练 0.472 → 测试 0.642 的先验偏移等于 logit 平移 0.697；平移后 Brier 0.1418、AUC 不变。
  → 漂移只改变概率"水平"，不改变"排序"。所以给绝对概率时要同时给同品类基准，别让用户拿 2023 年的绝对数去比 2016 年的直觉。

## 6. 文本到底值多少

TF-IDF 单通道 out-of-time AUC **0.7302**。对照：把"简介长度"单独当分数，v2 测试集上 AUC 只有 **0.527**
（文档早期版本报的 0.476 是旧口径，v2 已重算）——**文案的信息量在"说什么"，不在"说多少"**。

增量按品类（ΔAUC [95% CI]）：全体 **+0.0057 [0.0048, 0.0067]**；
film&video **+0.0098**、publishing **+0.0082**、art **+0.0083**、design **+0.0074**（四者显著）；
games +0.0016、technology +0.0025、comics +0.0020（不显著）。

**读法**：文本的价值在"叙事驱动"的品类（影视、出版、艺术、设计），不在"参数驱动"的品类（科技硬件、桌游配件）。
这比"文本有用/没用"这种二元结论有说服力得多，也正好回答文档里"TF-IDF 增量要按品类看"的要求。

## 7. 双目标：成功率 vs 成功时募资额

只用成功项目（train 167,173 / test 34,973）对 `log1p(usd_pledged)` 做分位数回归（P10/P50/P90）：

- pinball：P10 0.1058 / P50 0.3318 / P90 0.1865。
- **P10–P90 区间覆盖率 0.7412**（名义 0.80）：重尾下区间偏窄，如实报告；P50 被低估的比例 0.4591（≈ 理想 0.5）。

权衡表（按目标金额档）：

| 目标金额 | 平均预测成功率 | 预测中位募资 | 观测中位募资 |
|---|---|---|---|
| ≤1k | 0.872 | 1,435 | 1,608 |
| 1–5k | 0.785 | 5,025 | 5,378 |
| 5–10k | 0.750 | 12,705 | 13,027 |
| 10–20k | 0.714 | 21,499 | 20,975 |
| 20–50k | 0.671 | 47,057 | 50,890 |
| 50–100k | 0.614 | 117,865 | 117,580 |
| 100–500k | 0.605 | 352,512 | 377,915 |

→ 目标金额每上一档，成功率掉 5–10 个点，但成功时的募资中位翻倍以上。**"概率—募资"权衡曲线是真实存在的**，
不是修辞：这就是选题说明第三条输出要的东西。（>500k 档 n=4，不给结论。）

## 8. 平台面：月度成功率

204 个月的月度达标率，训练到 2022-12，2023-01 起滚动一步预测：

| 方法 | MAE | RMSE | 相对季节朴素 |
|---|---|---|---|
| **Holt-Winters 加性** | **0.01930** | 0.03418 | **0.825×** |
| Holt-Winters 乘性 | 0.02019 | 0.03400 | 0.864× |
| 季节朴素（去年同月）| 0.02338 | 0.04241 | 1.000× |
| 上一月 | 0.03953 | 0.05554 | 1.691× |

→ 时序模型打败朴素法，但**优势只有 17.5%，不是文档草案里写的 39.3%（0.607×）**。差异原因：v2 口径 +
区间改成 2023–2026 后重新评估。报告里用 0.825× 这个实测值。

## 9. 可解释件与落地件

- **LR 优势比**：`creator_prev_success_rate` OR **14.53 [13.90, 15.20]**（每 1.0 成功率）；`log_goal` 每 +1（=×10）
  OR **0.505**；目标 >500k OR 0.257；品类 crafts 0.430、journalism 0.493，theater 2.78、dance 2.28、music 1.66；
  发起人排名 >8th OR 1.736；`prev_miss`（无历史）OR 0.100。
- **置换重要性（test，AUC 下降）**：发起人既往成功率 **0.123**、log_goal 0.032、子品类 0.031、时长 0.014、上线小时 0.012、
  发起人排名 0.0075、州 0.0071；简介长度 0.0027、词数 0.0025（文本的价值在"说什么"而不是"说多少"）。
- **配置评分表**：204 格（品类 × 8 金额档 × 4 时长档，n_train ≥ 300），每格给达标率 + Wilson 95% CI + test 对照。
  最高：comics / ≤1k / 1–14 天 **0.936 [0.911, 0.954]**；最低：food / 50–100k / 46+ **0.022 [0.011, 0.044]**。
- **分品类关键词面板**：450 行（15 品类 × 30 词），log-odds + BH-FDR，全部显著。示例：
  games 正向 stl / zine / printable / miniatures（做打印即玩、模型件），负向 app / mobile / android / shooter（做手游/平台游戏）；
  publishing 正向 zine / anthology / hardcover，负向 would / trying；film&video 正向 relationship / short / student，
  负向 youtube / tv / show；music 正向 folk / pre-order，负向 rap / hip-hop。
  → "可交付的实物/可打印/可预订"语言相关系数高，"做 App/频道/预告"语言显著偏低。
  （配图只画了训练量最大的 4 个品类：film&video、music、publishing、games；其余品类在 CSV 里。）
- **示例卡**（3 张失败项目反事实）：目标金额 ×0.5 后预测概率从 0.025→0.073、0.082→0.182、0.193→0.540；
  目标金额 ×2 则全部降到 0.01–0.12。曲线单调，方向与经济学直觉一致。

## 10. 这些结果能说明什么 / 不能说明什么

**能说明**
1. 上线前的"配置 + 发起人 + 文案"已足够把成败排序做得很准（AUC 0.885，外推四年不衰减），头部十分位几乎必成。
2. 概率是可直接用的（ECE 0.003），但必须带同品类基准与 n，且要知道 2023 年后的绝对水平比历史高——"校准的是排序，不是水平"。
3. 降目标金额、缩短时长、写"实物/可交付"而非"愿景"的文案，都对成功率有方向明确、可量化的影响（关联，不是因果）。
4. 收益侧确实存在"低概率高募资"的权衡带，分位数回归给出了量级。

**不能说明**
1. 不能说因果：goal / duration 是发起人自选的，模型给的是"同品类同履历下，这样配置的历史达标率是多少"，不是"改了就会涨"。
2. 不能预测爆款：数据里没有流量、推荐、媒体曝光变量，>500k 档 n 太小。
3. 不能外推到非 USD 市场（港/日/欧被剔除）、不能外推到 2026 之后（末年样本不完整，2026 年只有 7 个月）。
4. 不能给"人"打分——发起人历史是项目级统计，不是信用评分。

## 1. 三分钟结论（任务一）

**模型没造假，解释越界了。**

| 维度 | 判定 | 一句话 |
|---|---|---|
| 结果泄露 | **A 通过** | 10 个结果列都没入模，标签只由 `state` 生成 |
| 时点正确性 | **B 需修订** | 履历按 `launch_dt` 截断，但决策点是 `created_at`，9,984 行（1.65%）"提前知道了结果" |
| 标签与切分 | **A 通过** | 时间切分严格、阈值只在 val 选；两处 RISK（用 test AUC 选模型、早停随机切 10%） |
| 指标口径 | **B 需修订** | 0.8823 / 0.1316 **我独立复现得到 0.88218 / 0.13165，是真的**；但 F1 0.856、top-10% 99.24% 已撞天花板，且基准率漂移 +18.2pp 没处理 |
| 评分卡 / 决策轴 / 文案 | **C 不可作为结论** | 评分卡 `mean_predicted` 与观测率相关 0.9963（等于复述历史）；决策轴建在不存在的原型项目上；"文案加长 −13pp"是**数据支撑之外的树跳变** |

**三件必须立刻改的事**

1. **撤回"文案加长降 13pp"**。该配置是 `blurb_words=40 / blurb_len=240`，而可建模样本里简介最长 **239 字符**、40 词只有 **1 行**、"≥35 词且≥200 字符"**0 行**。这不是剂量-反应，是模型在"绝迹区"返回的叶子均值。**执行完文本层后这一判定不变**：新模型在支撑域内的长度响应是倒 U，峰值 +3.0pp（`04_图表\figt7_length_response.png`）。
2. **评分卡不要叫"模型验证"**。它用 2009–2026 全部行、由同一个模型打分，73.5% 是训练期行。
3. **决策轴的 ΔP / E / risk 降级为"描述性关联"**。原型打分的基准概率与同格观测率平均差 **8.97pp**，100/250 个格差 >10pp；86.4% 格的"最优动作"都是"把目标降到 ≤$1k"——这是目标金额的单调梯度，不是洞察。

## 2. 文本层实测（任务二，已全量运行，2026-11-09，518.7 s）

同一批 604,629 行、同一时间切分（训练 ≤2020 / 验证 2021–22 / 测试 ≥2023 = 100,469）、同一组超参，只换特征表：

| 配置 | 特征 | test AUC | 95% CI | Brier |
|---|---|---|---|---|
| M0 无文本特征 | 14 | 0.88073 | [0.87886, 0.88280] | 0.13231 |
| M0b 保留标题去简介 | 16 | 0.88235 | [0.88047, 0.88429] | 0.13155 |
| **M1 仅长度词数（现状）** | 18 | **0.88218** | [0.88040, 0.88416] | 0.13165 |
| **M2 长度 + TF-IDF** | 19 | **0.89007** | [0.88817, 0.89194] | **0.12838** |
| **M3 TF-IDF 替换长度** | 15 | 0.88954 | [0.88761, 0.89150] | 0.12814 |

| 对比 | ΔAUC | 95% CI |
|---|---|---|
| 仅长度 vs 完全无文本 | +0.00145 | [+0.00105, +0.00187] |
| **TF-IDF 在长度之上** | **+0.00788** | [+0.00702, +0.00864] |
| TF-IDF vs 不用简介 | +0.00772 | [+0.00680, +0.00847] |
| 文本层总增量 | +0.00933 | [+0.00845, +0.01020] |

- **回答"字数/词数解释力弱"**：长度类特征全部价值 +0.0015，TF-IDF +0.0079，**5.4 倍**。
- **分品类**：Music +0.0284、Food +0.0203、Fashion +0.0154 …… Comics +0.0011（CI 跨 0，不显著）。结构弱的品类受益最大。
- **分年份**：2023–2026 每年都是 +0.007～+0.009，无一年失效。
- **长度响应（支撑域内）**：把超长简介截到 10–18 词，模型预测 +1.9～+3.0pp，倒 U 形；**不存在"越长越降"**。
- 文本单模 AUC：OOF 0.7455 / test 0.7799。

文本层真正的价值不止这 0.008：它把"文案这个杠杆"从一句说不清的话，变成**带支撑域、带置信区间**的结论。关键词面板与文档级归因（S6/S7）尚未做。

**顺带解释掉那个反直觉**：文案长度与成功在**全样本**上相关 −0.058，但**逐年相关在 0 附近、2023 年后转正**（+0.041~+0.050）——聚合负相关是时代混杂（词数 21.9→14.8，同期达标率 48.9%→70.0%），不是"越短越好"。

## 4. 边界：我做过什么、没做什么

**做过**：任务一全量审查；文本层 S0–S5（构造 `text_score`、五配置对比、配对 bootstrap、分品类/分年份、支撑域内长度响应、七张图）。

**没做**（本轮范围外）：

- **关键词面板 / 文档级归因 / 反事实建议卡（S6–S7）**。
- **没用新模型重跑评分卡与决策轴**：`scorecard.csv`、`decision_axes_cells.csv`、`score_demo.csv` 均未被覆盖；M2 的 pipeline 已存为 `model_histgb_text.joblib` 供后续复用。
- **没做去重敏感性**：1,001/100,463（0.996%）测试简介在训练窗逐字出现过，是文本模型的轻微记忆通道，已写进结果报告局限。
- **没修改包内既有文件**，也没动项目目录外任何文件。
- **有几项验不了**：`08_建模就绪数据\ks_model_ready_v1.parquet` 不在包内；`_build_model_ready.py` 的产物哈希无法核对；`0.8799` 的 pilot 复现无法重算。报告里这类数字都标了【无法验证】。
- **旧 `.joblib` 本机打不开**（sklearn 1.8.0 保存 vs 本机 1.5.1）；本次新存的 `model_histgb_text.joblib` 由本机 1.5.1 保存，可直接加载。

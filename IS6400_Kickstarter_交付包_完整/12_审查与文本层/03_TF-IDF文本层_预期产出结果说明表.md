# TF-IDF 文本层 · 预期产出结果说明表

> 说明：本表是**任务二（TF-IDF）实施前**的预期与验收契约，不是结果。所有"预期数值"来自三处实测基线：① 同工作区 `..\ks_v2` 的文本分支（另一口径，n=54k）；② 我在本包数据上做的 11 特征代理实验（n=160k 训练子样本 + 100,469 test）；③ **18 特征全量口径的端到端探针**（`04_复现与实测附录.md` §2）。三处方向一致，区间即由此给出。

> **实测锚点（2026-11-09 探针，非交付链路）**：18 特征 0.88218 → 18+`text_score` **0.89014**，ΔAUC **+0.00795**，CI95 [+0.00709, +0.00871]，Brier 0.13165 → 0.12845，text-only AUC 0.7548（OOF）/0.7799（test）。即本表 §1 第 3、4 行给出的区间已被一次独立实现**命中**，剩下的是把它做成正式管线 + 三张表。

## 0. 一句话预期

**文本层能把 test AUC 从 0.882 抬到 0.886–0.891（+0.004~+0.009，CI 不含 0），把 Brier 降 0.002–0.005；更重要的产出不是这点增量，而是三张能写进 PPT 的表：品类关键词面板、文档级正负词归因、支撑域内的文案反事实。**

## 2. 分品类预期区间（先验来自 `ks_v2` 实测，本包口径可能更强）

| 品类 | `ks_v2` 实测 ΔAUC | 本包预期 | 备注 |
|---|---|---|---|
| film & video | +0.0098 | +0.006 ~ +0.012 | 文案里"trailer/festival/16mm"信号强 |
| art | +0.0083 | +0.005 ~ +0.010 | 面板词最可读（如 residency、canvas） |
| publishing | +0.0083 | +0.004 ~ +0.009 | 作者/装帧类词 |
| design | +0.0074 | +0.004 ~ +0.009 | 材料/工艺词 |
| technology | +0.0025 | +0.001 ~ +0.005 | 硬件术语多，长度不敏感 |
| comics | +0.0021 | +0.001 ~ +0.004 | 与 games 同质 |
| games | +0.0016 | +0.001 ~ +0.004 | 结构特征已很强（占 top-10% 的 70.4%） |

**注意**：text-only AUC 高不代表增量高——games 的文本分不弱，但结构特征（目标/时长/履历）已经把信号吃干净了。这也是"top-10% 命中率不会因文本层明显变化"的原因（预计 99.2% ± 0.1pp）；**不要把"top-10% 变高"写进预期**。

## 3. 三个痛点的对照验收（叙事上的"完成"标准）

| 痛点 | 现在（交付包） | 补完文本层后的合格表述 | 合格判据 |
|---|---|---|---|
| "文案加长降 13pp 无法解释" | 一个不可解释的配置对照 | "该配置（40 词 / 240 字符）在数据中不存在（最大 239 字符）；模型的响应在 30 词后断崖，属外推；且长度与成功的原始相关是时代混杂（逐年相关≈0）" | 报告里同时出现：支撑域表 + 断崖曲线 + 逐年相关，三件齐全 |
| "文案杠杆无法给建议" | 只有两个长度标量 | 三类可读产出：① 品类关键词表（"该品类达标项目常用 demo/prototype，少用 cheap"）② 文档级归因（"你的简介里 video 帮你 +x，'app/mobile' 拉低 y"）③ 支撑域内改写（"改到同期 p95 长度，ΔP ≈ −1pp"） | 三类产出都有文件、都有 CI 或样本量、措辞都是"关联" |
| "文本维度不可解释" | 无特征重要度 | 面板 + 归因 + 支撑域三件套，且与 `text_score` 方向自洽 | 符号一致率 ≥70% |

## 4. 建议卡长什么样（示例，供 `advice_by_category_text.csv` 对齐）

```
【品类】Art（n=24,870，历史达标率 47.2%）
【目标/时长】当前 >$50k × 46–60d 档：历史达标率 4.8%（n=352，95%CI 3.0–7.6%）
【文案·高成功项目更常见】residency(+1.55) / canvas(+1.02) / gallery(+0.88)
【文案·高成功项目更少用】"will be"(−0.74) / "hopefully"(−0.61)
【这条建议的置信度】参考级（面板符号稳定性 62%，样本支撑充分）
【注意】以上为历史关联，非因果；文案改动幅度在同期 p95 长度以内约 ±1pp
```

> 写法纪律：不出现"应该改成 X 就能 +Ypp"；不出现"越短越好"；不出现没有任何支撑域说明的 ΔP。

## 6. 失败情形预案（fail-soft）

| 情形 | 判定 | 动作 |
|---|---|---|
| 增量 +0.002~+0.004，CI 下界 >0 | 弱但真实 | 主文报"小幅但稳健"，不作为核心卖点；关键词面板照样进主文（它不依赖增量） |
| 增量 CI 跨 0 | 未验证 | 文本层写进"探索性结果"附录；主结论不变；不写"提升了" |
| 词表泄漏迹象（删 test 后增量掉一半） | 不可用 | 回 S2 检查 fit 年份；若确认，整层重做 |
| 面板稳定率 <60% 的品类 >半数 | 覆盖不足 | 只对稳定品类给文案建议；其余品类文案列留空并注明原因 |
| 支撑域反事实出现 >±3pp | 可疑 | 检查是否越界或词表漂移；不接受则只报"幅度不可辨识" |
| 时间不够（<2 天） | 降级 | 只做 S0–S5（底座+增量），关键词面板与归因挪到附录；**三张表可以少一张，但 13pp 的解释不能少** |

## 二、四个问题的答案

**① 跨版本复现**：我们 1.8.0 重训的 LR+稀疏 test AUC **0.8554**（组员 1.5.1 报 0.8554）；HistGB+SVD128 **0.8842**（组员 0.8847）；RF+SVD128 **0.8609**（组员 0.8609） ⇒ 三个方向全部复现，差异 ≤0.002。

**② LR 的增益来自文本还是稀疏表示**：LR+稀疏 **+0.90pp**、LR+SVD128（与树模型同 354 特征）**+0.48pp**。⇒ 大部分增益需要**稀疏高频词表示**才能拿到；SVD 压缩后掉了 0.41pp。

**③ LR 正则是否偏松**：C 网格（0.1/0.3/1/3）test AUC 分别 0.8580(0.1)、0.8565(0.3)、0.8549(3.0)；C=1 为 **0.8554**。⇒ 峰值不在 C=1，正则设置值得复核。

**④ SVD 维数敏感性（HistGB）**：128维 0.8842、32维 0.8846、64维 0.8847、256维 0.8842。若随维数单调上升 ⇒ 仍欠拟合，还有空间；若已平台 ⇒ 维数不再是瓶颈。

## 三、过拟合体检结论

- val→test 的 AUC 差（gap）范围 **+1.60 ~ +2.42pp**，中位 **+2.07pp**；基线 LR/HGB 的 gap 为 +2.42 / +2.21pp。
- 判据：**加入文本后 gap 若明显放大（超过基线 1pp 以上）即为过拟合信号**；若 gap 与基线相当，则文本层带来的是真实泛化收益。
- 另看 Brier：若文本使 Brier 变差而 AUC 变好，通常意味着概率校准被破坏（过拟合征兆）。

## 四、定稿判读（人工复核，覆盖上文占位语）

1. **SVD 维数已饱和**：32 维 0.8846 / 64 维 **0.8847** / 128 维 0.8842 / 256 维 0.8842 —— 差异 ≤0.0005 且**不随维数单调上升** ⇒ 128 维不是瓶颈，继续加维无用；文本信号约在 32 维即榨干（与 SVD 累计解释方差 32→8.6%、128→20.4%、256→30.7% 一致）。
2. **LR 正则略偏松但影响很小**：稀疏表示 test AUC 随 C 单调下降（C=0.1 **0.8580** > 0.3 0.8565 > 1 0.8554 > 3 0.8549），最优仅比原设高 **+0.26pp**；SVD128 表示对 C 几乎不敏感（0.8512–0.8518）。
3. **过拟合不成立**：加入文本后 gap **缩小**而非放大（LR 2.42→1.62pp、HistGB 2.21→2.04pp），且 Brier 同时改善（LR 0.1507→0.1456、HistGB 0.1316→0.1300）。三条过拟合特征（gap 放大、Brier 变差、仅弱显著）全部不成立。
4. **跨版本可复现**：我们 1.8.0 重训与组员 1.5.1 在三个模型上一致（LR 0.8554 / HistGB 0.8842 vs 0.8847 / RF 0.8609），最大差 0.0005 ⇒ 文本层结论可跨环境引用。
5. **报告措辞**：应写"**稀疏词袋表示**使 LR 提升 0.90pp"，并注明 HistGB 仅 +0.24pp、RF −1.40pp；不可笼统写"文本提升 0.9pp"。

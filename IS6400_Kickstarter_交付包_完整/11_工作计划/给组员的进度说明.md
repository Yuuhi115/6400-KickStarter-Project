## 一、一句话概括

我们已经把一个"**上线前配置评分与建议工具**"的**引擎部分和两张核心表**做出来了：
用 60 万条历史项目训练出成功率模型（**AUC 0.8823**），并产出
① **配置评分卡**（450 格：品类×金额档×时长档的历史达标率 + 置信区间）
② **三个决策轴**（商业价值 / 干预潜力 / 风险），
可以对任意新配置给出"预测达标概率"和"改哪个杠杆能提升多少"。

## 二、做了什么（四步）

### 第 1 步：把数据做成"能直接训练的底座"

清洗后的 81 列还不能直接建模（金额混着 15 种币种、时长有 41.79% 被截断、文本长度把缺失当 0）。我们加了 11 个建模列：

| 新增列 | 解决什么 |
| --- | --- |
| `m_goal_usd` | 金额统一换算成美元（非 USD 占 31.26%，不换会让 >50k 档达标率高估 6.6pp） |
| `m_dur_days_exact` | 精确时长（旧列被截断） |
| `m_name_len` / `m_blurb_len` / `m_blurb_words` | 文本长度缺失即 NA（旧列算成 3 字符） |
| `m_split` | 预置时间切分（train ≤2022 / test ≥2023），防止误用随机切分 |
| `m_is_modelable` | 可建模掩码（canceled 不算失败） |

### 第 2 步：建模 + 验证

- 复现了组员的 pilot 设置（同超参、同切分），但换成我们的全量数据与修正口径；
- 对比 LR / 随机森林 / 梯度提升，**梯度提升（HistGB）最优**；
- 时间切分训练（**不用随机切分**，因为成功率从 2015 年 33.6% 涨到 2024 年 64.5%）；
- 阈值只在验证集上选；10 个事后列（pledged、backers_count、staff_pick…）全部排除。

### 第 3 步：模型落盘 + 打分能力

训练好的模型已保存（`model_histgb_ours.joblib`），**以后给新配置打分不需要重训**。

### 第 4 步：两张核心表

- **配置评分卡**：15 品类 × 6 金额档 × 5 时长档 = 450 格，每格给样本量、历史达标率、95% 置信区间、成功时中位募资；
- **决策三轴**：商业价值（期望募资额）、干预潜力（改杠杆能涨多少）、风险（期望损失）。

## 三、关键数字（汇报时只需要记这几个）

| 指标 | 数值 | 含义 |
| --- | ---: | --- |
| 可建模样本 | **604,629** | 成功率分母（不是 673,839） |
| 测试集规模 | **100,469**（2023 年之后） | 时间外验证，基准率 64.41% |
| **ROC-AUC** | **0.8823** | 区分能力（基线 0.5；组员 pilot 0.8571） |
| **PR-AUC** | 0.9295 | 关注"成功"时的精确率-召回 |
| **Brier** | 0.1316 | 概率校准（越低越好；基线 0.2710） |
| **Top-10% 实际成功率** | **99.24%**（总体 64.41%） | 排序价值：lift **1.54** |
| **评分卡覆盖率** | **96.6%** | 多少项目能落进 n≥300 的可用格 |
| 干预潜力高的项目占比 | **45.4%** | 改目标/时长能提升 ≥15pp 的那批 |

| 文件 | 用途 |
| --- | --- |

## 五、这些产出能怎么用（按角色分）

**① 写报告的同学**
- 第 2 章（数据）：用 `README_建模数据说明.md` + `dataset_profile`；
- 第 3 章（方法）：用 `S0_复刻结果.md` 的评估设计与 `decision_axes.md` 的口径；
- 第 4 章（结果）：直接用评分卡的 250 个可用格 + 决策三轴的四张表；

**② 做 PPT 的同学**
- 第 3 页（数据集）：已有一张视觉图（数据漏斗 + KPI + 字段表）；
- 第 4 步（方法/评分卡）：用 `config_scorecard_heatmap.png`；
- 第 6 页（贡献）：用 `decision_axes.png` + 反事实打分表（三种价值一目了然）。

**③ 准备答辩的同学**
- 必背三句话：
  1. "成功率分母是 604,629，canceled 不算失败"；
  2. "主指标是 AUC 0.8823 / Brier 0.1316，不用准确率（多数类就有 64.4%）"；
  3. "我们只做预测与关联，不做因果；只给配置打分，不给发起人打分"。

## 二、工作分解（6 个阶段，含产出与验收）

### 阶段 S0：复刻组员 pilot（**先做，1–2 天**）

**目的**：确认我们的全量口径能复现/超过 pilot，且没有隐性泄漏。

| 步 | 动作 | 产出 |
| --- | --- | --- |
| S0.1 | 写 `replicate_pilot.py`：读 parquet，按 `pilot方法规格.md` 第九节做 8 处口径替换（`m_log_goal_usd`、`m_dur_days_exact`、`m_name_len` 等、`creator_rank`、`subcategory_key`、`country_final`、`m_split`）；`prep_days` 用 `created_at`→`launched_at` 现场解析 | `09_分析脚本/replicate_pilot.py` |
| S0.2 | 同超参（LR `liblinear/3000`、RF `250/msl5`、HistGB `lr0.08/250/31/l2 1.0`）、`DummyClassifier(prior)` 基线、验证集选 F1 阈值 | 同脚本 |
| S0.3 | 评估：AUC / PR-AUC / Brier / 校准（10 bin quantile）/ 十分位 lift / 3 折 `TimeSeriesSplit` | `11_结果与报告/S0_复刻结果.md` + `s0_metrics.csv` |
| S0.4 | **消融**：① 去掉 `prep_days`；② USD-only vs 全样本；③ 加 TF-IDF vs 不加 | `S0_消融表.md` |

**验收**：全量 AUC ≥ 0.85；去掉 `prep_days` 后 AUC 不塌方（若塌方 → 说明该特征可疑，需查是否隐含结果信息）。

### 阶段 S1：特征与模型定稿（2–3 天）

| 步 | 动作 | 产出 |
| --- | --- | --- |
| S1.1 | TF-IDF：`name_clean` + `blurb_clean`，`max_features=3000, min_df=20, stop_words='english'`，与结构化特征拼接 | 特征管线脚本 |
| S1.2 | 特征白名单冻结 + 泄漏列 schema 断言（混入 3 个事后列 → AUC 应跳到 1.0000 的对照必须保留） | `11_结果与报告/特征白名单.md` |
| S1.3 | 模型定稿：LR（可解释，优势比）+ HistGB（性能上限）+ RF（稳健性对照）；报告三视角特征重要性 | `S1_模型对比.md` |

**验收**：TF-IDF 增量 ≥ +0.02 AUC（否则作为附录）；泄漏对照实验可复现；白名单写进代码断言。

- [ ] 时间切分无随机（`m_split`），特征选择/调参只在训练窗口内
- [ ] 四基线齐备，多数类 **0.6441** 同表出现

- [ ] 每个金额数字标币种口径（`m_goal_usd` / `usd_pledged`）
- [ ] 每个百分比有分母（604,629 / 504,160 / 100,469）
- [ ] 小格子已抑制（n≥300 + CI）+ 报覆盖率
- [ ] 每条建议带双目标代价
- [ ] 全文无因果表述
- [ ] 脚本可复现（清洗 8–9 min、建模数据 3–5 min、模型 < 15 min）

## 五、风险清单

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 全量重跑后 AUC 低于 pilot 的 0.857 | 报告基准被动 | 差距来自履历口径变化（更严格）→ 如实报告并解释，不用旧数字 |
| `prep_days` 隐性泄漏 | top-decile 虚高 | S0.4 消融；若塌方则剔除该特征并在报告说明 |
| 币种换算近似 | 金额类结论打折 | 用 `static_usd_rate` + 对照 USD-only 子样本 |
| 履历仍为 `retained_clean_sample` | 履历偏小 | 可用 `--raw` 重跑清洗（9 min）升级口径 |
| 450 格过稀 | 建议不可靠 | n≥300 + CI 不重叠才发言，并报覆盖率 |
| 报告超页 | 超出 20–25 页 | 先写 30 页再压，细节进附录 |
